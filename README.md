# 海报 / 封面 交付自检

上传一张海报或封面图，5 秒出结论：**比例对不对、发出去会被裁掉哪块、字够不够清楚、文件超没超限**，并可导出一页交付报告。

在线使用：https://lhm0601.github.io/haibao-check/

## 它会查什么

| 检查项 | 说明 |
|---|---|
| 比例 | 和目标平台比，≤2% 通过 / ≤6% 提醒 / >6% 不合格 |
| 裁切 | 压暗区＝发出去会被裁掉的部分，另标 92% 安全边距 |
| 清晰度 | 宽度是否达到平台建议像素 |
| 文件 | 格式与体积是否超常见上传限制 |
| 对比度 | 手动两点取色，按 WCAG AA / AAA 判定 |

## 平台规格（参考值）

小红书 3:4 1242×1660 ｜ 公众号首图 2.35:1 900×383 ｜ 朋友圈 1:1 1080×1080 ｜ 视频号 16:9 1080×608 ｜ 抖音 9:16 1080×1920

## 特点

- **单文件、零依赖、无后端**：打开即用，断网也能用
- **图片不上传**：全部在浏览器本地用 Canvas 处理
- 报告可导出 PNG，适合发客户或走审批时附上

## 本地运行

直接用浏览器打开 `index.html` 即可。
